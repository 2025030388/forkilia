# Forkilia
Sistema de gestión para emprendedores de comida (Java, Servlets, MySQL).

## Requisitos
- Java, Apache Tomcat 9 y MySQL 8.0 o superior

## Cómo ejecutarlo
1. Importa base_de_datos/forkilia.sql en MySQL.
2. Pon tu contraseña de MySQL en ConexionBD.java.
3. Ejecuta el proyecto desde NetBeans con Tomcat 9.
